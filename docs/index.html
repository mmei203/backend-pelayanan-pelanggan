⚡ API Pelayanan

🔐 Autentikasi User 👥 Manajemen User 📋 Data Pengaduan Pelanggan 📄 Cetak & Laporan

Dokumentasi API Backend Pelayanan Keluhan

Panduan integrasi frontend untuk otentikasi, master user, dan penanganan aduan pelanggan.

Base URL: /api

🔐 1. Autentikasi & Akun User

POST /api/auth/login
Login dengan username atau email beserta password. Menghasilkan JWT token.
Request Body (JSON):
{
  "identifier": "admin_cs", // Bisa berupa username atau email
  "password": "password123"
}
Response (200 OK):
{
  "success": true,
  "message": "Login berhasil",
  "data": {
    "user": {
      "idUser": "3c90a1b2-4d5e-6f7a-8b9c-0d1e2f3a4b5c",
      "namaUser": "Admin Customer Service",
      "email": "cs@pald.co.id",
      "username": "admin_cs",
      "role": "CS"
    },
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
GET /api/auth/me Bearer Token Required
Mendapatkan informasi profil user yang sedang login saat ini.
Headers:
Authorization: Bearer
Response (200 OK):
{
  "success": true,
  "data": {
    "idUser": "3c90a1b2-4d5e-6f7a-8b9c-0d1e2f3a4b5c",
    "namaUser": "Admin Customer Service",
    "email": "cs@pald.co.id",
    "username": "admin_cs",
    "role": "CS",
    "createdAt": "2026-11-10T00:00:00.000Z"
  }
}
PUT /api/auth/profile Bearer Token Required
Mengubah nama, username, email, atau password akun user yang sedang login.
Request Body (JSON):
{
  "namaUser": "Nama Baru",
  "username": "username_baru",
  "email": "email_baru@pald.co.id",
  "oldPassword": "password123", // Wajib jika ingin ganti password
  "newPassword": "newPassword456"
}
Response (200 OK):
{
  "success": true,
  "message": "Profil akun berhasil diperbarui",
  "data": {
    "user": {
      "idUser": "3c90a1b2-4d5e-6f7a-8b9c-0d1e2f3a4b5c",
      "namaUser": "Nama Baru",
      "email": "email_baru@pald.co.id",
      "username": "username_baru",
      "role": "CS"
    },
    "token": "eyJhbGciOi..." // Token baru dengan payload terupdate
  }
}
POST /api/auth/logout Bearer Token Required
Endpoint logout (frontend silakan hapus token dari localStorage/Cookie).
Response (200 OK):
{
  "success": true,
  "message": "Logout berhasil. Silakan hapus token di sisi klien/frontend."
}

👥 2. Manajemen Master User

GET /api/users
Mengambil daftar seluruh user pegawai (Super Admin, CS, Operator, Pengawas).
Response (200 OK):
{
  "success": true,
  "data": [
    {
      "idUser": "uuid",
      "namaUser": "Operator 1",
      "email": "op1@pald.co.id",
      "username": "operator1",
      "role": "Operator",
      "createdAt": "2026-11-10T00:00:00.000Z"
    }
  ]
}
POST /api/users
Membuat user baru (Role opsi: Super Admin, CS, Operator, Pengawas). Password otomatis di-hash.
Request Body (JSON):
{
  "namaUser": "Budi Pengawas",
  "email": "budi@pald.co.id",
  "username": "budi_pengawas",
  "password": "password123",
  "role": "Pengawas"
}

📋 3. Data Pengaduan Pelanggan

GET /api/pelanggan
Mengambil semua data pengaduan beserta data pelanggan, penerima, dan penanganinya.
Query Parameters (Optional):
?search=budi&sumberAduan=Pelanggan&saluranKeluhan=WhatsApp
POST /api/pelanggan
Membuat aduan baru pelanggan (dibuat oleh CS).
Request Body (JSON):
{
  "idUserCS": "3c90a1b2-4d5e-6f7a-8b9c-0d1e2f3a4b5c",
  "namaPelanggan": "Ahmad Dani",
  "noHp": "081234567890",
  "noKontakPdam": "12345678", // Kosongkan jika Non Pelanggan
  "alamat": "Jl. Kertak Hanyar No. 12",
  "keluhan": "Pipa bocor di depan pagar",
  "sumberAduan": "Pelanggan", // Pelanggan | Non Pelanggan
  "saluranKeluhan": "WhatsApp" // WhatsApp | Telepon | Datang Ketempat
}
PUT /api/pelanggan/:id
Update status pengaduan (ON PROGRESS atau SELESAI). Mendukung Multipart Form-Data untuk upload gambar bukti.
Form Data Fields (Multipart):
status: "ON PROGRESS" | "SELESAI"
operatorId: "uuid-operator"
keluhan: "Teks keluhan terupdate"
latitude: "-3.316694"
longitude: "114.590111"
dokumenLaporan: (File binary / pdf / gambar)
fotoKeluhan: (File binary / gambar bukti)

📄 4. Cetak PDF & Riwayat

GET /api/pelanggan/:id/print
Mengunduh/membuka file Formulir Aduan Pelanggan dalam bentuk PDF resmi (header logo PALD).
